# 기능 명세

> widget-studio 의 데이터 흐름과 위젯 갱신 규칙.

## 데이터

- 저장 위치 — 실기기는 키체인 공유 그룹(`$(AppIdentifierPrefix)io.github.s12171934.widgetstudio.shared`, 같은 키 이름의 generic password 항목), 키체인을 쓸 수 없는 시뮬레이터는 App Group `group.io.github.s12171934.widgetstudio`. 무료 팀은 App Group 을 쓸 수 없다.
  - 디자인 목록: `designs.v1` 키, `[WidgetDesign]` JSON.
  - 사진·GIF 표시 범위: 디자인의 `imageLayouts`에 `small`·`medium`·`large`·`extraLarge`별 `mode`(fill/fit)·`zoom`(1~3)·`horizontal`·`vertical`(-1~1)을 저장한다. 없는 키는 채우기·100%·가운데를 쓴다.
  - 기능 설정: `checklistItems`(항목 UUID·문구), `counterStart`·`counterStep`·`counterGoal`, `focusMinutes`를 디자인에 보관한다. 구버전 디자인에는 빈 목록·시작 0·단위 1·목표 10·25분을 기본값으로 채운다.
  - 진행 상태: `activity.v1.<디자인 UUID>`에 `WidgetActivity` JSON(완료 항목 UUID 집합·카운터 값·타이머 종료 시각·정지 시 남은 초)을 따로 보관한다. 디자인 저장은 이 키를 덮지 않는다.
  - 포모도로: 디자인의 `pomodoroSettings`에 집중·짧은 휴식·긴 휴식 시간과 회차를 저장한다. 진행 상태의 `pomodoro`에는 시작 시 설정·시작 시각·이전 경과 초를 저장하며 이전 JSON에는 기본 25/5/15분·4회와 실행 전 상태를 적용한다.
  - 포모도로 표시: `pomodoroAppearance`는 `digital`(숫자형)·`dial`(빨간 시계)이며 이전 JSON에는 `digital`을 적용한다. 표시 방식과 진행 기록은 독립적이다.
  - GIF 위젯 프레임: `gif-frames.v1.<디자인 UUID>` 키에 PNG 16장을 binary plist로 보관한다. 긴 변은 220px 이하, 읽기 예산은 4MiB다.
  - 예시 디자인 투입 여부: `seeded.v1`. 한 번 넣은 뒤 목록을 비워도 다시 넣지 않는다.
  - 배경 사진: `photo.<디자인 UUID>` 키. 위젯 메모리 한도와 항목 크기 때문에 긴 변 900px·JPEG 0.75 로 줄여 저장한다. GIF의 첫 장면도 같은 키에 긴 변 900px 이하의 PNG로 보관한다(투명도 유지).
- GIF 원본 — 앱 전용 `Application Support/GIFs/<디자인 UUID>.gif`. 무료 팀에서도 위젯은 대표 이미지와 작은 PNG 장면들만 공유받고 원본 파일을 읽지 않는다. 원본은 원자적 파일 쓰기와 최초 잠금 해제 이후 접근 가능한 파일 보호로 저장한다.
- 앱이 디자인을 저장·삭제·복제하면 `WidgetCenter.reloadAllTimelines()` 로 위젯을 다시 그리게 한다.

## 위젯 구성

- `AppIntentConfiguration` + `SelectDesignIntent`(매개변수 `design: DesignEntity?`).
- `DesignQuery` 는 저장소의 디자인 전체를 제안한다. 고른 디자인이 지워졌거나 고르지 않았으면 첫 디자인, 디자인이 하나도 없으면 「앱에서 디자인을 만들어 주세요」를 보여 준다.
- 지원 크기 — `systemSmall`·`systemMedium`·`systemLarge`·`systemExtraLarge`. 앱·확장은 iPhone·iPad를 지원하며, X-large는 iPad 홈 화면에서만 선택할 수 있다([Apple Widgets 지원표](https://developer.apple.com/design/human-interface-guidelines/widgets)).

## 기능 위젯

- 체크리스트 — 앱에서 최대 20개 항목을 편집하며 빈 항목은 저장에서 제외한다. 크기별 표시 한도는 작게·중간 2개, 크게 7개, X-large 14개다. 나머지는 개수로 안내하고 위젯의 배경 영역을 눌러 편집기로 연다.
- 카운터 — 시작 값, 1~1000 증감 단위, 목표를 설정한다. +·−는 정수 범위를 넘기지 않으며 초기화는 시작 값으로 돌린다. 크게·X-large는 목표 진행률과 보조 문구를 함께 표시한다.
- 집중 타이머 — 1~180분. 시작 시 종료 시각을 저장하고 `Text(timerInterval:countsDown:)`으로 남은 시간을 표시한다. 일시 정지는 남은 초를 보관하고 재개는 그 시간부터 시작한다. 만료 후 시작하면 설정된 시간으로 다시 시작하며 초기화는 정지한 초기 상태로 돌아간다. 소리·로컬 알림은 제공하지 않는다.
- 포모도로 — 기본 집중 25분·짧은 휴식 5분·긴 휴식 15분·4회. 집중은 1~180분, 짧은 휴식은 1~60분, 긴 휴식은 1~120분, 회차는 1~12회다. 긴 휴식 뒤 다음 묶음의 첫 집중으로 자동 전환한다.
- 포모도로 진행 — 경과 시간에서 현재 단계·회차·누적 집중 완료 횟수를 계산한다. 정지 중에는 경과 시간이 늘지 않는다. 실행 중 설정을 바꿔도 기존 세션은 시작 시 설정을 유지하며 초기화 후 새 설정을 사용한다. 별도 백그라운드 타이머나 종료 알림은 쓰지 않는다.
- 포모도로 기본 디자인 — `pomodoroSeeded.v1`을 확인해 「포모도로 25/5」를 목록 끝에 한 번 추가한다. 삭제한 뒤에는 다시 만들지 않는다.
- 포모도로 원형 — `PomodoroDial`은 항상 60분 눈금과 빨간 부채꼴을 그린다. 남은 시간이 5분보다 많으면 숫자는 숨기고, 5분이 되는 순간부터 숫자 카운트다운을 보여 준다. 60분을 넘는 시간은 빨간 원 전체로 표시한다. 큰 위젯은 큰 원형 시계, 중간·X-large는 시계와 조작·진행 정보를 나란히 배치한다.
- 원형 갱신 — 앱 미리보기·정지 상태는 `PomodoroSector`를 그린다. 실행 중 홈 위젯은 `Text(timerInterval:countsDown:)`와 번들의 자리별 부채꼴 글꼴을 쓴다. 시·분·초 각 자리의 원형 구간을 상위 자리 마스크로 합성하며, 별도 앱 타이머·잦은 타임라인 갱신을 추가하지 않는다. 홈 화면에서 연속으로 감소하는지는 실기기 검증이 남아 있다.
- 원형 글꼴 — Swift 빌드 도구가 60분 눈금의 `Fill`·`Select` 글꼴을 만들고 CoreText로 숫자 매핑을 검증한다. 생성물은 `.build/WidgetFonts`에만 둔다. 합자 조형은 사용하지 않는다.
- 원형 크기 — 홈 위젯은 타임라인 컨텍스트의 `displaySize`에서 내용 여백을 빼 실제 크기로 배치한다. 앱 미리보기에서는 화면 폭에 맞춘 크기를 사용한다.
- 원형 기본 디자인 — `pomodoroDialSeeded.v1`을 확인해 「빨간 타이머 25/5」를 한 번 추가한다. 기존 숫자형 디자인은 바꾸지 않고 두 디자인은 서로 다른 진행 기록을 갖는다.
- 월간 달력 — 로컬 달력의 월·첫 요일을 따르며 오늘을 강조한다. 큰 가로 공간에서는 오늘 날짜·요일·메모와 월 달력을 나란히 표시한다.
- 버튼 — `Button(intent: WidgetActionIntent(...))`가 디자인·동작·항목 식별자를 전달한다. 공유 저장소의 진행 상태만 바꾸고 타임라인을 새로 읽는다. 앱을 열지 않는다([Apple 위젯 상호작용](https://developer.apple.com/documentation/widgetkit/adding-interactivity-to-widgets-and-live-activities)).
- 독립성 — 같은 디자인을 쓰는 위젯은 기록을 공유한다. 복제는 새 디자인 UUID를 쓰므로 새 기록으로 시작한다. 디자인 삭제는 진행 상태도 지운다.
- 미리보기 — 같은 렌더링 뷰를 쓰며 버튼은 메모리 안의 복사본만 조작한다. 홈 화면 진행 상태는 바뀌지 않는다.

## 홈 화면 표시 방식 (Liquid Glass)

- 위젯은 `widgetRenderingMode` 로 기본(`fullColor`)과 유리(`accented` — 틴트·클리어 홈 화면)를 가른다.
- 유리 모드에서는 시스템이 `containerBackground` 를 걷어 내고 유리로 바꾼다. 글자는 사용자 글자 색을 버리고 흰색 계열로 그리며, `widgetAccentable()` 로 표시한 강조 그룹(시각·D-day 숫자·문구 제목·사진 제목)만 또렷하고 나머지는 흐리다.
- 사진 템플릿은 배경이 걷히므로 사진을 내용 층에 `widgetAccentedRenderingMode(.accentedDesaturated)` 로 올린다. 가장자리까지 채우려고 `contentMarginsDisabled()` 를 켜고 내용에 16pt 여백을 직접 준다.
- 어느 모양으로 그릴지는 iOS 홈 화면 설정만 정한다. 앱에는 표시 방식 설정이 없고, 미리보기 카드는 기본 모드 모습만 그린다.
- 예전 판의 「스크린샷 잘라내기 유리」 데이터(`wallpaper.v1`·`size.*`·`glass.*`)는 앱 시작 때 한 번 지운다(`legacyGlassRemoved.v1`).

## GIF 가져오기·재생

- 템플릿 — `gif`. 제목·보조 문구·어둡게 정도를 설정하며 홈 화면에서 앱을 열지 않고 반복 재생한다.
- 가져오기 — 사진 보관함은 현재 인코딩을 유지한 `PhotosPicker`, 파일은 `GIFFilePicker`의 GIF 전용 네이티브 선택기(`UIDocumentPickerViewController`, 복사 모드)를 쓴다. 선택 후 앱 미리보기에서 재생할 수 있으며 저장 전 취소하면 디자인 저장소에 원본·대표 이미지를 쓰지 않는다.
- 프리셋 — 별빛 여행·두근 하트·한밤의 꽃·푸른 물결·네온 궤도·비 오는 창·픽셀 비트·달빛 구름 8종. `GIFPreset`이 320×320px·36프레임·프레임당 0.08초의 GIF를 선택 시 생성한다. 자체 그림을 사용하며 외부 파일·네트워크·앱 번들 이미지 자산에 의존하지 않는다.
- 프리셋 선택 — 그리드에서는 첫 장면을 보여 주고, 선택하면 백그라운드에서 GIF를 생성·검증한다. 편집기에 원본·대표 장면을 적용하고 어둡게 정도를 0으로 둔다. 새 디자인의 기본 이름은 프리셋 이름으로 바꾸며, 기존 사용자 이름은 유지한다. 실제 파일 저장은 「저장」을 눌렀을 때만 한다.
- 검색 — `GIFSourceSheet`의 「GIF 찾기」에서 검색어를 넣고 브라우저의 Pixabay·GIPHY·Tenor 검색 페이지를 연다. 공백·한글·예약 문자는 경로에 맞게 인코딩하며, 비어 있으면 각 사이트의 GIF 시작 페이지를 연다. 검색 API나 계정 키는 사용하지 않는다.
- 다운로드 파일 연결 — 사이트에서 GIF를 저장한 뒤 「다운로드한 GIF 불러오기」를 누르면 라이브러리 안에서 파일 선택기를 연다. 선택한 파일을 백그라운드에서 검증해 편집기에 적용하고 라이브러리를 닫는다. 파일 선택을 취소하면 검색 화면·검색어·기존 GIF를 유지한다.
- 제한 — GIF 형식, 전체 파일과 각 프레임의 완결 상태를 확인한다. 최대 12MiB·300프레임이며 가로·세로는 각각 8192px 이하, 프레임 면적은 최대 16,777,216픽셀이다. 실패하면 원래 선택을 유지하고 오류를 안내한다.
- 시간 — 프레임별 GIF 지연 시간을 읽는다. 0.02초 미만이거나 유효하지 않은 지연은 0.1초, 10초보다 긴 지연은 10초로 처리한다. 원본의 반복 횟수와 관계없이 앱 화면에서는 반복 재생한다.
- 재생 — 앱의 `CADisplayLink`가 현재 프레임을 정하고, 직렬 백그라운드 큐가 ImageIO로 긴 변 600px 이하 이미지를 추출한다. `NSCache` 비용 한도는 24MiB이며 전 프레임을 미리 펼치지 않는다. 일시 정지는 장면을 유지하고, 앱 비활성 상태에서는 디코딩·재생을 멈춘다.
- 복제·삭제 — 복제는 원본 GIF와 공유 대표 PNG·위젯 프레임을 새 UUID로 복사한다. 삭제는 앱 원본·공유 대표 이미지·위젯 프레임·디자인을 함께 지운다. GIF를 다른 템플릿으로 바꿔 저장하면 원본 GIF를 지운다.
- 홈 화면 — 원본의 프레임 지연을 반영해 전체 재생 시간을 16구간으로 샘플링하고 2초 루프로 표시한다. 원본과 재생 속도·해상도·프레임 수가 같지는 않다. `GIFWidgetAnimationView`가 각 `Image`를 타이머 마스크로 교체하며, 앱이 전면에 없어도 시스템이 갱신한다. 마스크 글꼴은 Swift 빌드 도구로 만들고 위젯 `UIAppFonts`에 포함한다. 비공개 API·동적 글꼴·반복 타임라인 재요청은 쓰지 않는다.
- 이관 — 앱의 백그라운드 작업이 위젯 프레임 없는 기존 GIF를 변환한다. 원본·대표 이미지는 덮어쓰지 않고, 변환 중 삭제·교체된 파일은 건너뛴다. 완료 시 타임라인을 다시 읽는다. 프레임이 아직 없으면 대표 이미지로 표시한다.
- 홈 화면 모드 — 각 GIF 장면도 `widgetRenderingMode`를 따르며, 클리어·틴트에서는 `accentedDesaturated`로 표시한다. 앱에 별도 유리 모드 선택기를 추가하지 않는다.

## 크기별 화면 설정

- 사진·GIF 편집기의 미리보기에서 네 크기를 선택한 뒤 해당 크기의 화면 설정을 바꾼다. X-large는 별도의 배치 키를 쓰며 좁은 화면에서는 미리보기를 같은 비율로 축소한다.
- 맞춤은 채우기/전체 보기, 확대는 100~300%, 가로·세로 위치는 -100~100%다. 「이 크기 초기화」는 선택한 크기 설정만 지운다.
- `WidgetImageLayout.imageRect`가 원본 비율과 위젯 영역으로 표시 사각형을 계산하고, `WidgetImageView`를 앱 미리보기·사진·GIF의 모든 장면이 공유한다. GIF를 정사각형으로 먼저 자르지 않고 실제 위젯 비율에 맞춘다.
- 설정은 디자인 저장 시 반영한다. 전체 보기의 남는 영역은 기본 모드에서 디자인 배경, 클리어·틴트에서 시스템 배경을 보여 준다.

## 앱 아이콘

- 본 앱은 `Assets.xcassets/AppIcon.appiconset`의 불투명 1024px 아이콘을 사용한다. 유리 위젯 타일로 구성한 Liquid Glass 테마다.
- 내장 imagegen으로 생성했다. 제작 프롬프트는 「남보라·산호색 배경의 굴절하는 유리 위젯 타일, 글자 없는 정면 앱 아이콘」이다.

## 타임라인

| 템플릿 | 항목 | 갱신 정책 |
| --- | --- | --- |
| 시계 | 현재 분부터 60개, 1분 간격 | `.atEnd` |
| D-day | 지금 + 앞으로 7일의 자정 | `.atEnd` |
| 월간 달력 | 지금 + 앞으로 7일의 자정 | `.atEnd` |
| 체크리스트·카운터 | 지금 1개 | `.never` (버튼 조작·앱 저장 시 다시 그림) |
| 집중 타이머 | 지금 + 실행 중이면 종료 시각 | `.never` (시스템이 남은 시간을 표시하며 종료 항목에서 완료 표시) |
| 포모도로 | 지금 + 다음 두 묶음의 집중·휴식 단계 경계. 빨간 시계는 각 단계의 남은 5분 시점도 포함 | 실행 중 `.atEnd`, 정지 중 `.never` (시스템이 남은 시간을 표시, 단계 갱신 시점은 OS가 결정) |
| 문구·사진·GIF | 지금 1개 | `.never` (앱 저장 시 다시 그림, GIF는 시스템 타이머 마스크가 장면 교체) |

## 딥링크

- `widgetstudio://design/<UUID>` — 위젯을 누르면 그 디자인의 편집기를 연다.
- `widgetstudio://play/<UUID>` — GIF 위젯을 누르면 해당 GIF의 앱 내 재생 화면을 연다. 다른 템플릿이면 편집기를 연다.
- 개발용 실행 인자 `-openDesign <UUID>` — 시뮬레이터에서 터치 없이 편집기를 열어 확인할 때 쓴다(`simctl launch … -openDesign <UUID>`).
