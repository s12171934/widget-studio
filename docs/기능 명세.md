# 기능 명세

> widget-studio 의 데이터 흐름과 위젯 갱신 규칙.

## 데이터

- 저장 위치 — 실기기는 키체인 공유 그룹(`$(AppIdentifierPrefix)io.github.s12171934.widgetstudio.shared`, 같은 키 이름의 generic password 항목), 키체인을 쓸 수 없는 시뮬레이터는 App Group `group.io.github.s12171934.widgetstudio`. 무료 팀은 App Group 을 쓸 수 없다.
  - 디자인 목록: `designs.v1` 키, `[WidgetDesign]` JSON.
  - 예시 디자인 투입 여부: `seeded.v1`. 한 번 넣은 뒤 목록을 비워도 다시 넣지 않는다.
  - 배경 사진: `photo.<디자인 UUID>` 키. 위젯 메모리 한도와 항목 크기 때문에 긴 변 900px·JPEG 0.75 로 줄여 저장한다. GIF의 첫 장면도 같은 키에 긴 변 900px 이하의 PNG로 보관한다(투명도 유지).
- GIF 원본 — 앱 전용 `Application Support/GIFs/<디자인 UUID>.gif`. 무료 팀에서도 위젯은 대표 이미지만 공유받고 원본 파일을 읽지 않는다. 원본은 원자적 파일 쓰기와 최초 잠금 해제 이후 접근 가능한 파일 보호로 저장한다.
- 앱이 디자인을 저장·삭제·복제하면 `WidgetCenter.reloadAllTimelines()` 로 위젯을 다시 그리게 한다.

## 위젯 구성

- `AppIntentConfiguration` + `SelectDesignIntent`(매개변수 `design: DesignEntity?`).
- `DesignQuery` 는 저장소의 디자인 전체를 제안한다. 고른 디자인이 지워졌거나 고르지 않았으면 첫 디자인, 디자인이 하나도 없으면 「앱에서 디자인을 만들어 주세요」를 보여 준다.

## 홈 화면 표시 방식 (Liquid Glass)

- 위젯은 `widgetRenderingMode` 로 기본(`fullColor`)과 유리(`accented` — 틴트·클리어 홈 화면)를 가른다.
- 유리 모드에서는 시스템이 `containerBackground` 를 걷어 내고 유리로 바꾼다. 글자는 사용자 글자 색을 버리고 흰색 계열로 그리며, `widgetAccentable()` 로 표시한 강조 그룹(시각·D-day 숫자·문구 제목·사진 제목)만 또렷하고 나머지는 흐리다.
- 사진 템플릿은 배경이 걷히므로 사진을 내용 층에 `widgetAccentedRenderingMode(.accentedDesaturated)` 로 올린다. 가장자리까지 채우려고 `contentMarginsDisabled()` 를 켜고 내용에 16pt 여백을 직접 준다.
- 어느 모양으로 그릴지는 iOS 홈 화면 설정만 정한다. 앱에는 표시 방식 설정이 없고, 미리보기 카드는 기본 모드 모습만 그린다.
- 예전 판의 「스크린샷 잘라내기 유리」 데이터(`wallpaper.v1`·`size.*`·`glass.*`)는 앱 시작 때 한 번 지운다(`legacyGlassRemoved.v1`).

## GIF 가져오기·재생

- 템플릿 — `gif`. 제목·보조 문구·어둡게 정도를 설정하며 홈 화면에는 첫 장면과 「GIF 재생」 표시를 보여 준다.
- 가져오기 — 사진 보관함은 현재 인코딩을 유지한 `PhotosPicker`, 파일은 GIF 전용 파일 선택기를 쓴다. 선택 후 앱 미리보기에서 재생할 수 있으며 저장 전 취소하면 원본·대표 이미지를 쓰지 않는다.
- 제한 — GIF 형식, 전체 파일과 각 프레임의 완결 상태를 확인한다. 최대 12MiB·300프레임이며 가로·세로는 각각 8192px 이하, 프레임 면적은 최대 16,777,216픽셀이다. 실패하면 원래 선택을 유지하고 오류를 안내한다.
- 시간 — 프레임별 GIF 지연 시간을 읽는다. 0.02초 미만이거나 유효하지 않은 지연은 0.1초, 10초보다 긴 지연은 10초로 처리한다. 원본의 반복 횟수와 관계없이 앱 화면에서는 반복 재생한다.
- 재생 — 앱의 `CADisplayLink`가 현재 프레임을 정하고, 직렬 백그라운드 큐가 ImageIO로 긴 변 600px 이하 이미지를 추출한다. `NSCache` 비용 한도는 24MiB이며 전 프레임을 미리 펼치지 않는다. 일시 정지는 장면을 유지하고, 앱 비활성 상태에서는 디코딩·재생을 멈춘다.
- 복제·삭제 — 복제는 원본 GIF와 공유 대표 PNG를 새 UUID로 복사한다. 삭제는 앱 원본·공유 대표 이미지·디자인을 함께 지운다. GIF를 다른 템플릿으로 바꿔 저장하면 원본 GIF를 지운다.
- 홈 화면 — 실제 GIF 재생은 하지 않는다. GIF 대표 장면도 사진과 같이 `widgetRenderingMode`를 따르고, 클리어·틴트에서는 `accentedDesaturated`로 표시한다.

## 타임라인

| 템플릿 | 항목 | 갱신 정책 |
| --- | --- | --- |
| 시계 | 현재 분부터 60개, 1분 간격 | `.atEnd` |
| D-day | 지금 + 앞으로 7일의 자정 | `.atEnd` |
| 문구·사진·GIF 대표 장면 | 지금 1개 | `.never` (앱 저장 시 다시 그림) |

## 딥링크

- `widgetstudio://design/<UUID>` — 위젯을 누르면 그 디자인의 편집기를 연다.
- `widgetstudio://play/<UUID>` — GIF 위젯을 누르면 해당 GIF의 앱 내 재생 화면을 연다. 다른 템플릿이면 편집기를 연다.
- 개발용 실행 인자 `-openDesign <UUID>` — 시뮬레이터에서 터치 없이 편집기를 열어 확인할 때 쓴다(`simctl launch … -openDesign <UUID>`).
