# 기능 명세

> widget-studio 의 데이터 흐름과 위젯 갱신 규칙.

## 데이터

- 저장 위치 — 실기기는 키체인 공유 그룹(`$(AppIdentifierPrefix)io.github.s12171934.widgetstudio.shared`, 같은 키 이름의 generic password 항목), 키체인을 쓸 수 없는 시뮬레이터는 App Group `group.io.github.s12171934.widgetstudio`. 무료 팀은 App Group 을 쓸 수 없다.
  - 디자인 목록: `designs.v1` 키, `[WidgetDesign]` JSON.
  - 예시 디자인 투입 여부: `seeded.v1`. 한 번 넣은 뒤 목록을 비워도 다시 넣지 않는다.
  - 배경 사진: `photo.<디자인 UUID>` 키. 위젯 메모리 한도와 항목 크기 때문에 긴 변 900px·JPEG 0.75 로 줄여 저장한다.
- 앱이 디자인을 저장·삭제·복제하면 `WidgetCenter.reloadAllTimelines()` 로 위젯을 다시 그리게 한다.

## 위젯 구성

- `AppIntentConfiguration` + `SelectDesignIntent`(매개변수 `design: DesignEntity?`).
- `DesignQuery` 는 저장소의 디자인 전체를 제안한다. 고른 디자인이 지워졌거나 고르지 않았으면 첫 디자인, 디자인이 하나도 없으면 「앱에서 디자인을 만들어 주세요」를 보여 준다.

## 홈 화면 표시 방식 (Liquid Glass)

- 위젯은 `widgetRenderingMode` 로 기본(`fullColor`)과 유리(`accented` — 틴트·클리어 홈 화면)를 가른다.
- 유리 모드에서는 시스템이 `containerBackground` 를 걷어 내고 유리로 바꾼다. 글자는 사용자 글자 색을 버리고 흰색 계열로 그리며, `widgetAccentable()` 로 표시한 강조 그룹(시각·D-day 숫자·문구 제목·사진 제목)만 또렷하고 나머지는 흐리다.
- 사진 템플릿은 배경이 걷히므로 사진을 내용 층에 `widgetAccentedRenderingMode(.accentedDesaturated)` 로 올린다. 가장자리까지 채우려고 `contentMarginsDisabled()` 를 켜고 내용에 16pt 여백을 직접 준다.
- 앱의 미리보기 카드는 같은 `DesignContent` 를 쓰고, 유리 모드는 실제 `glassEffect`(틴트: `.regular.tint`, 클리어: `.clear`)로 배경화면 위에 그린다. 틴트 색은 배경화면마다 하나다.

## 유리(투명) 배경

- iOS 에는 위젯 하나만 유리로 그리게 하는 API 가 없다. 위젯은 배경화면을 볼 수 없으므로 `glassEffect` 도 비칠 것이 없다.
- 그래서 앱이 빈 홈 화면 스크린샷(`wallpaper.v1`)에서 크기별 자리(`glassRects`, 스크린샷 기준 정규화 좌표)를 잘라 흐림(`glassBlur`, pt)·어둡게(`glassDim`)를 적용한 그림을 `glass.<UUID>.<small|medium|large>` 로 저장한다. 위젯은 그 그림을 `containerBackground` 로 깔고 위쪽 옅은 빛과 테두리 빛만 얹는다.
- 자리 사각형 크기는 위젯 확장이 타임라인 때 남긴 실제 표시 크기(`size.<family>`)를, 없으면 화면 폭 비율 추정값을 쓴다.
- 시스템 막 상쇄 — 홈 화면은 기본 모드에서 위젯 위에 옅은 밝은 막(불투명도 약 0.099, 색 약 228·226·229)을 덮는다. iOS 27.2 시뮬레이터 라이트·다크에서 전후 화면을 회귀해 잰 값이며, 그림을 만들 때 미리 거꾸로 걷어 내 주변 배경화면과 이어지게 한다(잔여 약 0.03). 앱 안 미리보기 그림에는 적용하지 않는다.
- 스크린샷을 바꾸면 유리 배경을 쓰는 모든 디자인의 그림을 다시 만든다. 사진 템플릿은 사진이 배경이라 유리를 쓰지 않는다.
- 홈 화면이 틴트·클리어이면 시스템이 `containerBackground` 를 걷고 진짜 유리로 바꾸므로, 이 그림은 기본 모드에서만 보인다.

## 타임라인

| 템플릿 | 항목 | 갱신 정책 |
| --- | --- | --- |
| 시계 | 현재 분부터 60개, 1분 간격 | `.atEnd` |
| D-day | 지금 + 앞으로 7일의 자정 | `.atEnd` |
| 문구·사진 | 지금 1개 | `.never` (앱 저장 시 다시 그림) |

## 딥링크

- `widgetstudio://design/<UUID>` — 위젯을 누르면 그 디자인의 편집기를 연다.
- 개발용 실행 인자 `-openDesign <UUID>` — 시뮬레이터에서 터치 없이 편집기를 열어 확인할 때 쓴다(`simctl launch … -openDesign <UUID>`). `-appearance tinted|clear` 는 목록의 표시 방식을 고른다. `-glassTestShot <png> -glassTestRect x,y,w,h` 는 UI 테스트가 첫 디자인을 흐림 0 유리 배경으로 바꿀 때 쓴다.
